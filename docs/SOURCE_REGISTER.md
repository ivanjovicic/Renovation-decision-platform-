# Source Register

Sources are evidence inputs, not automatically truth. Public price guides are intentionally treated as lower-confidence than normalized real quotes/actuals.

## S1 — RZS - Stambene zgrade (Popis 2022)
https://stat.gov.rs/sr-latn/vesti/20240509-stambene-zgrade/?a=0&s=0101

2.261.051 stambena zgrada; najveća grupa izgrađena 1961-1980 (745.485 zgrada).

## S2 — RZS - Stanovi prema svojini i korišćenju
https://popis2022.stat.gov.rs/sr-latn/5-vestisaopstenja/news-events/24082023-stanovi-gustina-nastanjenosti/

97,9% stanova je u privatnoj svojini; snažan signal da je homeowner segment relevantan.

## S3 — RZS - Građevinarstvo
https://stat.gov.rs/sr-latn/oblasti/gradjevinarstvo/

Širi indikator građevinske aktivnosti; 785,4 mlrd RSD vrednosti izvedenih radova 2025. Nije direktan TAM renoviranja.
